# 🌾 Harvest Dash: The Great Chase

A satirical infinite runner game built with HTML5 and JavaScript. 

### 🎮 How to Play
- **Jump:** Avoid hurdles by jumping over them.
- **Sickle Swipe:** Use the sickle to clear obstacles and gain bonus points.
- **Goal:** Keep the chase going as long as possible!

### 🚀 Tech Stack
- HTML5 Canvas
- JavaScript (Vanilla)
- Hosted on GitHub Pages

### 📱 Mobile Friendly
This game is optimized for mobile browsers with on-screen touch controls.
